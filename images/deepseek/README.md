## 用的时候注意

- `main.png` 现在是**白底**原图（不是透明底）。要往深色背景上贴，先用 `chibi-transparent.png`，或者等主人同意后再做一版透明立绘。
- `three-views.png` 是设定图，用来对齐发型和体型，不是成品素材。
